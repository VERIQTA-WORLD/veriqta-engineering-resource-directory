# DevOps Platform Engineer Resource Directory

You work on providing supported delivery capabilities that other engineers can use through predictable interfaces. The question that organizes this collection is: **Can a team complete a supported workflow and recover from failure without depending on undocumented platform knowledge?**

## Start with the work

A portal generates repositories successfully, but users cannot deploy because downstream permissions and ownership were never defined. You need a supported onboarding and deployment path, not just a successful scaffolding action.

A portal is one interface to a platform. Platform ownership includes service behavior and lifecycle support; application teams retain the responsibilities defined by the platform contract.
