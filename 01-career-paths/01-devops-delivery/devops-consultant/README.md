# DevOps Consultant Resource Directory

You work on assessing delivery constraints, testing improvement hypotheses, and transferring usable capabilities to client teams. The question that organizes this collection is: **Which change addresses the demonstrated constraint, and what evidence would show it helped?**

## Start with the work

A client reports that releases are slow and requests Kubernetes. Deployment records instead suggest long approval queues and repeated environment repair. You must establish an evidence-based engagement and avoid a tool-first recommendation.

Consulting authority comes from the agreed scope, access, and client decision process. Findings are not permission to change systems, and a recommendation is not an implemented outcome.
