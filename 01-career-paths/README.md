# Engineering career resource collections

Browse resources by the engineering work you do or want to investigate. Career titles vary across organizations; use a collection’s stated scope and task categories to decide whether it fits your responsibilities.

Each career collection organizes tools, official documentation, architecture references, learning resources, practical projects, operational guidance, standards, and neighboring careers. These are resource directories, not compulsory courses.

**Collection status:** the six DevOps delivery careers have populated resource collections undergoing final review. The remaining 214 career folders are being developed. Category navigation below covers the full 220-career scope; a navigation link does not imply that its destination already contains reviewed resources.

## Use a collection by task

Open **toolkit** for implementation options, **official documentation** for precise behavior, **reference architectures** for design choices, and **production responsibilities** for operating resources. Use **learning resources** and **labs and projects** for topic study and practice; check access, prerequisites, resource creation, costs, and cleanup before running an external exercise. **Standards and frameworks** distinguishes specifications from advisory guidance. **Related careers** explains real neighboring collections and their status.

Some titles appear in more than one category because the same work can be discovered through different contexts. Those paths remain part of the directory; they will be cross-referenced as the collections are completed. Do not infer a resource ID from a career folder name.
