# Cloud Reliability Engineer: Related Career Paths

Which cloud dependencies and failure domains determine the workload’s actual recovery capability? When the next observation points to a different responsibility, use the routes below.

## [Infrastructure Reliability Engineer](../infrastructure-reliability-engineer/README.md)

This route focuses on keeping infrastructure and its change-control dependencies operable, recoverable, and appropriately isolated. Ask: **Can you repair or rebuild the environment when the infrastructure control path itself is impaired?**

Open [architecture resources](../infrastructure-reliability-engineer/infrastructure-reliability-engineer-architecture-resources.md) for the design boundary, or [production practices](../infrastructure-reliability-engineer/infrastructure-reliability-engineer-production-practices.md) when you have an operating observation to investigate.

## [Database Reliability Engineer](../database-reliability-engineer/README.md)

This route focuses on protecting database correctness, availability, performance, and recoverability as connected responsibilities. Ask: **Can you preserve correct data and useful service behavior through overload, replication failure, and restoration?**

Open [architecture resources](../database-reliability-engineer/database-reliability-engineer-architecture-resources.md) for the design boundary, or [production practices](../database-reliability-engineer/database-reliability-engineer-production-practices.md) when you have an operating observation to investigate.

## [Resilience Engineer](../resilience-engineer/README.md)

This route focuses on designing and validating continued operation, controlled degradation, and recovery under disruption. Ask: **What useful service remains during disruption, and can the system recover without unacceptable data loss?**

Open [architecture resources](../resilience-engineer/resilience-engineer-architecture-resources.md) for the design boundary, or [production practices](../resilience-engineer/resilience-engineer-production-practices.md) when you have an operating observation to investigate.
