# Cloud Reliability Engineer Resource Directory

You work on making cloud workloads dependable across managed services, identity, quotas, networking, and recovery boundaries. The question that organizes this collection is: **Which cloud dependencies and failure domains determine the workload’s actual recovery capability?**

## Start with the work

A workload spans two zones, but deployment, credentials, and backups depend on a shared regional path. The team assumes multi-zone placement is sufficient recovery protection.
