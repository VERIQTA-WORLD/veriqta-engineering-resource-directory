# Capacity Engineer Resource Directory

You work on matching usable resources to current and forecast demand under performance and failure constraints. The question that organizes this collection is: **How much demand can you serve while meeting the latency and recovery requirements, including a lost failure domain?**

## Start with the work

Traffic is growing, CPU averages appear comfortable, and queue delay rises sharply during peaks. One availability zone may also be unavailable. You need to explain usable headroom and the next capacity decision.
