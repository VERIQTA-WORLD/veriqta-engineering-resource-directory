# Scalability Engineer Resource Directory

You work on understanding how workload growth changes bottlenecks, coordination, resource demand, and service behavior. The question that organizes this collection is: **Which limit constrains useful throughput next, and will the proposed scaling action actually relieve it?**

## Start with the work

Adding application replicas stops improving throughput. Database connection counts rise, one tenant dominates a partition, and tail latency worsens.
