# Service Reliability Engineer Resource Directory

You work on connecting service ownership, user journeys, objectives, dependencies, releases, and recovery. The question that organizes this collection is: **Which user outcome defines service health, and what evidence supports accepting or stopping a change?**

## Start with the work

A service reports high availability, but successful checkout falls during a release because its health endpoint does not exercise the payment dependency.
