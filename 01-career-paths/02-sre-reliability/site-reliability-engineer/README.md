# Site Reliability Engineer Resource Directory

You work on applying software engineering to service reliability, operational workload, release safety, and incident learning. The question that organizes this collection is: **Which engineering change will sustainably improve service reliability or reduce recurring operational work?**

## Start with the work

An on-call team repeatedly restarts a service to clear incidents. Pages consume engineering time, releases continue through rapid error-budget consumption, and no durable improvement is owned.
