# Infrastructure Reliability Engineer Resource Directory

You work on keeping infrastructure and its change-control dependencies operable, recoverable, and appropriately isolated. The question that organizes this collection is: **Can you repair or rebuild the environment when the infrastructure control path itself is impaired?**

## Start with the work

A cluster incident also makes the runner and state backend used for recovery unavailable. Some persistent volumes hold data that infrastructure definitions cannot recreate.
