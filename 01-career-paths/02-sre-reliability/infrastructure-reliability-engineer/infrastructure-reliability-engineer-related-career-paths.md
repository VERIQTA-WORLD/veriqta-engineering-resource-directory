# Infrastructure Reliability Engineer: Related Career Paths

Can you repair or rebuild the environment when the infrastructure control path itself is impaired? When the next observation points to a different responsibility, use the routes below.

## [Cloud Reliability Engineer](../cloud-reliability-engineer/README.md)

This route focuses on making cloud workloads dependable across managed services, identity, quotas, networking, and recovery boundaries. Ask: **Which cloud dependencies and failure domains determine the workload’s actual recovery capability?**

Open [architecture resources](../cloud-reliability-engineer/cloud-reliability-engineer-architecture-resources.md) for the design boundary, or [production practices](../cloud-reliability-engineer/cloud-reliability-engineer-production-practices.md) when you have an operating observation to investigate.

## [Platform Reliability Engineer](../platform-reliability-engineer/README.md)

This route focuses on operating shared developer capabilities with explicit tenant boundaries, consumer objectives, and recoverable workflows. Ask: **Can consumers complete supported tasks when a shared controller, integration, or identity service is degraded?**

Open [architecture resources](../platform-reliability-engineer/platform-reliability-engineer-architecture-resources.md) for the design boundary, or [production practices](../platform-reliability-engineer/platform-reliability-engineer-production-practices.md) when you have an operating observation to investigate.

## [Network Reliability Engineer](../network-reliability-engineer/README.md)

This route focuses on maintaining dependable connectivity through naming, routing, transport, policy, and failure-domain analysis. Ask: **At which boundary does the connection fail, and which observation distinguishes the competing causes?**

Open [architecture resources](../network-reliability-engineer/network-reliability-engineer-architecture-resources.md) for the design boundary, or [production practices](../network-reliability-engineer/network-reliability-engineer-production-practices.md) when you have an operating observation to investigate.
