# Database Reliability Engineer Resource Directory

You work on protecting database correctness, availability, performance, and recoverability as connected responsibilities. The question that organizes this collection is: **Can you preserve correct data and useful service behavior through overload, replication failure, and restoration?**

## Start with the work

A primary database slows down, replicas lag, and applications open more connections. A failover is proposed while an archive gap leaves the restore capability uncertain.
