# Network Reliability Engineer Resource Directory

You work on maintaining dependable connectivity through naming, routing, transport, policy, and failure-domain analysis. The question that organizes this collection is: **At which boundary does the connection fail, and which observation distinguishes the competing causes?**

## Start with the work

Only one region reports intermittent connection timeouts. DNS resolution succeeds, aggregate traffic appears normal, and a recent network-policy change is suspected.
