# DNS: Names, Answers, and Caches

Choose resources that make the lookup path visible, rather than treating every DNS failure as the same problem.

## Focused references

**[Cloudflare: What is DNS? →](https://www.cloudflare.com/learning/dns/what-is-dns/)**  
Follow the roles involved in a lookup before examining server configuration.  
**Free explanation**

**[How DNS Works →](https://howdns.works/)**  
Use the illustrated explanation to build a first picture of DNS resolution.  
**Free illustrated website**

**[RFC 1034: Domain Names, Concepts and Facilities →](https://www.rfc-editor.org/rfc/rfc1034)**  
Read the foundational specification alongside later DNS references; it is not the complete current DNS standard set.  
**Free specification; advanced reference**
