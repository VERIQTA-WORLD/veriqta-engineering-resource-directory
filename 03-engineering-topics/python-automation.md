# Python for Automation

Choose a real parsing or API task, then study the Python needed to complete it.

## Learn through small programs

**[Automate the Boring Stuff with Python →](https://automatetheboringstuff.com/)**  
Al Sweigart; choose a small automation task and study the relevant Python chapter.  
**Free online reading; paid editions**

**[Python Tutor →](https://pythontutor.com/)**  
Step through small synthetic programs and inspect their changing state.  
**Interactive teaching website; feature limits vary**

**[Exercism →](https://exercism.org/)**  
Select a programming-language track and solve small exercises.  
**Free; account needed for platform features**

**[The Missing Semester →](https://missing.csail.mit.edu/)**  
Lessons and exercises for shell workflows, version control, debugging, and other everyday tools.  
**Free course material**
