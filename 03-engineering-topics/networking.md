# Networking: Follow the Traffic

Start with how data moves, then choose a capture, lab, or reference for the layer you need.

## Build the mental model

**[Networking Fundamentals →](https://www.practicalnetworking.net/index/networking-fundamentals-how-data-moves-through-the-internet/)**  
Follow the free introductory module on how data moves through networks.  
**Free module; further training separate**

**[Computer Networks: A Systems Approach →](https://book.systemsapproach.org/)**  
Larry Peterson and Bruce Davie; connect protocols to the systems they support.  
**Free online textbook**

**[Stanford CS144 →](https://cs144.github.io/)**  
Study computer networking through a university course and programming assignments.  
**Public material; C++ and systems prerequisites**

**[Subnetting practice →](https://subnetipv4.com/)**  
Practise IPv4 subnet questions and check your reasoning.  
**Free learning website**

**[containerlab →](https://containerlab.dev/)**  
Build reproducible network labs from topology definitions.  
**Free documentation and source; compatible host and images required**

**[Beej’s Guide to Network Programming →](https://beej.us/guide/bgnet/)**  
Brian Hall; work through socket programming when you need the application-side view of networking.  
**Free online book; C familiarity**

## Put one idea to work

Draw a small lab topology and explain a successful and a failed connection from observations. Use the selected guide’s prerequisites and verification steps. Choose an owned or provided learning environment, keep sensitive data out of your notes, and remove the exercise resources when finished.
