# Cloud Cost Management

Choose resources that make resource ownership and workload cost visible.

## Connect cost to an engineering choice

| Open | What you can find | Access |
| --- | --- | --- |
| [FinOps Framework](https://www.finops.org/framework/) | Connect cloud cost work with allocation, ownership, and engineering decisions. | Public framework |
| [AWS Architecture Center](https://aws.amazon.com/architecture/) | Browse architecture material by workload and service concern. | Public architecture catalog |
| [Azure Architecture Center](https://learn.microsoft.com/en-us/azure/architecture/) | Compare architecture guidance with your workload’s requirements. | Public architecture catalog |
| [Google Cloud Architecture Center](https://cloud.google.com/architecture) | Find a provider design matching the problem you need to investigate. | Public architecture catalog |
