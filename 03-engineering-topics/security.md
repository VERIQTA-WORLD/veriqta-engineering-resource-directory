# Security Foundations and Practice

Connect a control with the risk it addresses, the authority it uses, and the evidence that it works.

## Study a boundary

| Open | What you can find | Access |
| --- | --- | --- |
| [Security Engineering](https://www.cl.cam.ac.uk/archive/rja14/book.html) | Ross Anderson; choose a security-design chapter to understand the assumptions around a control. | Author-hosted material; edition access varies |
| [Web Security Academy](https://portswigger.net/web-security) | Choose a vulnerability explanation and its authorized training lab. | Free learning and labs; account for progress |
| [OWASP Top 10](https://owasp.org/www-project-top-ten/) | Identify the edition and use it to orient further application-security study. | Free awareness resource |
| [OWASP Juice Shop](https://owasp.org/www-project-juice-shop/) | Use an intentionally vulnerable application as an authorized security training target. | Free source; isolated learning environment required |
| [OWASP DevSecOps Guideline](https://owasp.org/projects/devsecops-guideline) | Explore security practices across software delivery. | Free project guidance |

## Put one idea to work

Use an authorized learning application to explain one finding and verify an intended access boundary. Use the selected guide’s prerequisites and verification steps. Choose an owned or provided learning environment, keep sensitive data out of your notes, and remove the exercise resources when finished.
