# Version Control with Git

Study the commit graph behind the collaboration or recovery question you have.

## See the history move

**[Pro Git →](https://git-scm.com/book/en/v2)**  
Scott Chacon and Ben Straub; read the chapter matching the Git operation you need to understand.  
**Free online book**

**[Learn Git Branching →](https://learngitbranching.js.org/)**  
Use the visual exercises to examine commits and branch movement.  
**Free interactive exercises**

**[Visualizing Git →](https://git-school.github.io/visualizing-git/)**  
Explore a small commit graph before trying a history-changing operation on a real repository.  
**Free interactive website**

**[The Missing Semester →](https://missing.csail.mit.edu/)**  
Lessons and exercises for shell workflows, version control, debugging, and other everyday tools.  
**Free course material**
