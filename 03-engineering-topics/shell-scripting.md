# Shell Scripting

Learn the parts of the shell that make a small automation task understandable and repeatable.

## Read the script’s behavior

**[The Linux Command Line →](https://linuxcommand.org/tlcl.php)**  
William Shotts; build a working understanding of the shell, files, permissions, and scripts.  
**Free PDF; paid print editions**

**[BashGuide →](https://mywiki.wooledge.org/BashGuide)**  
Study shell behavior through a community-maintained guide.  
**Free guide**

**[The Missing Semester →](https://missing.csail.mit.edu/)**  
Lessons and exercises for shell workflows, version control, debugging, and other everyday tools.  
**Free course material**

**[ShellCheck →](https://www.shellcheck.net/)**  
Examine a shell snippet and connect reported issues to the relevant explanation.  
**Free interactive tool**

**[explainShell →](https://explainshell.com/)**  
Inspect how supported command arguments relate to manual text.  
**Free interactive website**

**[OverTheWire Bandit →](https://overthewire.org/wargames/bandit/)**  
Practise shell navigation and problem solving through progressive levels.  
**Free; SSH client required**

## Put one idea to work

Test a small script with empty input, a malformed record, and filenames containing spaces. Use the selected guide’s prerequisites and verification steps. Choose an owned or provided learning environment, keep sensitive data out of your notes, and remove the exercise resources when finished.
