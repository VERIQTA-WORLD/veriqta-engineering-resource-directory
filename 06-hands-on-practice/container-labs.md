## Make the exercise useful

Build a small owned application image and change one runtime setting without rebuilding unrelated inputs. Keep the image reference, runtime configuration, and an actual application request.

**Environment and cleanup:** Remove exercise containers and unneeded images or volumes; check whether any registry or hosted resources remain.
