# Find Somewhere to Practise

Choose a format and a clear outcome. The collection pages help you compare environments, prerequisites, and the evidence to keep.

| Explore | What you can discover |
| --- | --- |
| [Browser Labs](browser-labs.md) | Use a hosted environment when you want to begin an exercise without assembling the whole lab yourself. |
| [Playgrounds and Interactive Explainers](playgrounds.md) | Choose an interactive view when you want to explore an idea before changing a real system. |
| [Linux and Shell Challenges](linux-challenges.md) | Choose an exercise that makes you investigate files, processes, permissions, or service behavior. |
| [Networking Labs and Captures](networking-labs.md) | Practise a network question in a topology you can draw and control. |
| [Container Labs](container-labs.md) | Follow an application from a build definition into a running container. |
| [Kubernetes Labs](kubernetes-labs.md) | Choose a workload problem before adding cluster extensions. |
| [Cloud Labs](cloud-labs.md) | Read the billing and cleanup conditions before starting a provider exercise. |
| [Security Labs](security-labs.md) | Choose a deliberately vulnerable application or a clearly authorized training environment. |
| [Automation Exercises](automation-exercises.md) | Start with a small task you can explain manually, then automate only its understood behavior. |
| [Troubleshooting Challenges](troubleshooting-challenges.md) | Find a scenario where you have to choose evidence before making a change. |
| [Project Collections](project-collections.md) | Choose a project with an outcome you can demonstrate and a scope you can finish. |
| [Performance and Failure Labs](performance-and-failure-labs.md) | Begin with a hypothesis, a small load or fault, and an explicit stop condition. |
