# Kubernetes Labs

Choose a workload problem before adding cluster extensions.

## Find a guided route

| Open | What you can find | Access |
| --- | --- | --- |
| [Killercoda](https://killercoda.com/) | Choose a browser scenario or playground with a clear task and prerequisites. | Free and paid options; session limits |
| [Kube by Example](https://kubebyexample.com/) | Choose a focused Kubernetes learning path or exercise. | Public learning material; environment requirements vary |
| [Kubernetes 101 with Jeff Geerling](https://kube101.jeffgeerling.com/) | Follow an application through Kubernetes concepts with a creator’s recorded teaching series. | Free video series; check current APIs |
| [Google Cloud microservices demo](https://github.com/GoogleCloudPlatform/microservices-demo) | Read and deploy a sample application when you need a multi-service workload for a lab. | Free source; infrastructure charges may apply |

## Make the exercise useful

Deploy a sample application, verify traffic through its Service, and investigate a reversible configuration error. Keep the resource definition, events, and application request showing recovery.

**Environment and cleanup:** Delete the learning cluster or namespace as appropriate, then check external volumes, addresses, load balancers, and registry artifacts separately.
