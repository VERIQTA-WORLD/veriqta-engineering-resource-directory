# Microsoft Azure: Learning and Practice

Use the Azure service you need as the entry point rather than trying to learn the whole provider at once.

## Choose a learning format

| Open | What you can find | Access |
| --- | --- | --- |
| [Azure training](https://learn.microsoft.com/en-us/training/azure/) | Select a module matching the Azure service you are using. | Free reading; exercise accounts and charges vary |
| [Azure Friday](https://learn.microsoft.com/en-us/shows/azure-friday/) | Discover demonstrations and conversations around Azure services. | Free video series; demonstrations may use paid infrastructure |
| [Azure documentation](https://learn.microsoft.com/en-us/azure/) | Choose the service guide and language or command-line examples you use. | Free reference; Azure usage can incur charges |
| [Azure Architecture Center](https://learn.microsoft.com/en-us/azure/architecture/) | Compare architecture guidance with your workload’s requirements. | Public architecture catalog |
| [Microsoft cloud security benchmark](https://learn.microsoft.com/en-us/security/benchmark/azure/overview) | Check the benchmark version and control guidance before applying it. | Public guidance; inspect preview status |

## Choose a bounded exercise

Choose a module with an explicit exercise, keep its resource scope separate, and explain one successful workload request. Check the selected guide’s permissions, region, account, and resource requirements before starting. Follow its teardown, revoke temporary access, and inspect retained disks, snapshots, addresses, logs, or other billable resources afterward.
