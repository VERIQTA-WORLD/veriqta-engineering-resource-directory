# Interactive Learning Websites

Change an input, predict what should happen, and compare the result.

## Explore a concept directly

| Open | What you can find | Access |
| --- | --- | --- |
| [Learn Git Branching](https://learngitbranching.js.org/) | Use the visual exercises to examine commits and branch movement. | Free interactive exercises |
| [Visualizing Git](https://git-school.github.io/visualizing-git/) | Explore a small commit graph before trying a history-changing operation on a real repository. | Free interactive website |
| [Python Tutor](https://pythontutor.com/) | Step through small synthetic programs and inspect their changing state. | Interactive teaching website; feature limits vary |
| [SQLBolt](https://sqlbolt.com/) | Practise SQL queries in short browser lessons. | Free interactive exercises |
| [PostgreSQL Exercises](https://pgexercises.com/) | Solve queries against a consistent sample dataset and compare your approach. | Free exercises |
| [OPA Playground](https://play.openpolicyagent.org/) | Compare policy decisions against small synthetic inputs. | Free interactive tool |
| [Kyverno Playground](https://playground.kyverno.io/) | Explore a policy against sample Kubernetes resources. | Public playground; no confidential manifests |
| [curl converter](https://curlconverter.com/) | Compare a synthetic curl command with a generated client-code representation. | Free interactive website; keep secrets out of inputs |
| [regex101](https://regex101.com/) | Explore a regular expression against synthetic text using the matching engine you choose. | Free interactive website; no secrets in inputs |
| [Subnetting practice](https://subnetipv4.com/) | Practise IPv4 subnet questions and check your reasoning. | Free learning website |

## Before you choose

Use synthetic inputs. An interactive explanation can help you reason about a command or policy without establishing that it is safe in your environment.
