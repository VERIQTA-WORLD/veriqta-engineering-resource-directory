## Try a small task

Write a small HTTP client with tests covering a successful response and an error.

**Keep:** The test cases and the behavior you expect from the client.

**Setup:** synthetic files or a disposable host for administrative changes. **Cleanup:** altered settings, test accounts, keys, and learning VMs.
