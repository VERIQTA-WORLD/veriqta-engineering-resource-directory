## Try a small task

Create two branches with conflicting edits, merge them, and explain the chosen resolution.

**Keep:** The graph before and after the merge, plus the resolved diff.

**Setup:** Git and a disposable local repository. **Cleanup:** keep your notes and remove the test repository when finished.
