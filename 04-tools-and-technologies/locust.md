## Try a small task

Model one synthetic user interaction and run it against an owned local service with a small user limit.

**Keep:** The task, request rate, and response observations.

**Setup:** owned target, bounded load or fault, explicit stop condition. **Cleanup:** stop generators, undo faults, and verify recovery.
