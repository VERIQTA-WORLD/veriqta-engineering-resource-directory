## Try a small task

Configure a small service on a disposable VM and run the playbook twice.

**Keep:** The inventory and the observations that explain the second run.

**Setup:** dedicated learning scope; cloud examples can incur charges. **Cleanup:** test resources, retained images or storage, and temporary access.
