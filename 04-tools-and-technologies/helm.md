## Try a small task

Change one chart value, render the output, and compare it with the previous manifest.

**Keep:** The values diff and the specific rendered resource it changes.

**Setup:** disposable cluster with suitable privileges. **Cleanup:** workloads, cluster resources, and separately created volumes, load balancers, or credentials.
